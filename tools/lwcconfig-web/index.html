Das Tool spricht über dieselbe USB-HID-Verbindung wie die LED-Wiz-Software. Änderungen werden mit „Anwenden“ sofort wirksam, aber erst mit „Speichern“ dauerhaft im EEPROM abgelegt.

WS2811 / WS2812-Strip

Jeder LED-Wiz-Ausgang kann einen Farbkanal eines Pixelbereichs steuern. Während der Strip beschrieben wird, sind Interrupts kurz gesperrt (~30 µs je Pixel) – lange Strips lassen GPIO-PWM leicht flackern.

Ausgänge 1–32 (LED-Wiz)

#TypPinInvertiert Pixel abAnzahlKanalTest

Eingänge (Taster, Joystick-Richtungen, Encoder)

Taster schalten standardmäßig gegen GND (interner Pull-up). „Shift“ aktiviert für alle anderen Eingänge die zweite Funktion. Der Punkt zeigt den Live-Zustand.
#PinFunktionMit ShiftAktiv highLive

Analoge Joystick-Achsen

Potis/Hall-Sensoren an ADC-fähigen Pins. Min/Mitte/Max mit den Knöpfen aus dem Live-Wert übernehmen. Die Totzone (0–100 %) um die Mitte gibt 0 aus, außerhalb wird wieder auf den vollen Bereich skaliert.
#PinJoystickAchseInvertiert MinMitteMaxTotzoneLiveAusgabe

LED-Wiz-ID

Die ID (1–16) bestimmt, als welches LED-Wiz-Gerät sich der Klon meldet. Nach dem Neustart neu verbinden.

Sicherung

Die Datei enthält die komplette Pin-Belegung dieses Boards.

Wartung

Werkseinstellungen werden erst mit „Speichern“ dauerhaft. Der Bootloader dient zum Flashen neuer Firmware (Leonardo/Micro: avrdude, Breakout: Atmel FLIP/dfu-programmer).
