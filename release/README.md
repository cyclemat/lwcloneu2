# Fertige Firmware / built firmware

Hier liegen die gebauten `.hex`-Dateien aller Boards und die `manifest.json` (Version, Datum, Dateigrößen).
**Der Online-Flasher** (<https://cyclemat.github.io/lwcloneu2/flash.html>) **bedient sich aus diesem Ordner.**
Erzeugt von `firmware/publish.sh` nach `firmware/build.sh`. Alles **(Beta)** – noch nicht an Hardware getestet.

| Datei | Board / Chip |
|---|---|
| `arduino_leonardo.hex` | Arduino Leonardo / Micro (ATmega32U4), mit DOF-COM-Port |
| `arduino_promicro.hex` | SparkFun Pro Micro (ATmega32U4), mit DOF-COM-Port |
| `arduino_mega2560__m2560.hex` | Arduino Mega 2560 – Hauptchip ATmega2560 |
| `arduino_mega2560__m16u2.hex` | Arduino Mega 2560 – USB-Chip ATmega16U2 (Brücke) |
| `arduino_uno__m328.hex` | Arduino Uno – Hauptchip ATmega328P |
| `arduino_uno__m16u2.hex` | Arduino Uno R3 – USB-Chip ATmega16U2 (Brücke) |
| `arduino_uno__m8u2.hex` | Arduino Uno R1/R2 – USB-Chip ATmega8U2 (Brücke) |
| `breakout_32u2.hex` | Breakout-Board ATmega32U2 |
| `arduino_due.bin` | Arduino Due (SAM3X8E, nativer USB-Port, 3,3 V) – rohes Abbild ab 0x80000 für SAM-BA/bossac, mit DOF-COM-Port |

This folder holds the built `.hex` files for all boards plus `manifest.json` (version, date, sizes).
**The web flasher downloads its firmware from here.** Generated by `firmware/publish.sh` after `firmware/build.sh`.
Everything is **(Beta)** – not yet tested on real hardware.
