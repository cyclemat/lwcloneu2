LWCloneU2 LED-Wiz-Klon für Arduino

GitHub

Flashen und einrichten – direkt im Browser

LWCloneU2 macht aus einem Arduino einen LED-Wiz-kompatiblen Ausgabetreiber mit 32 Ausgängen, Tastern, Joystick-Achsen und WS2811/WS2812-Strip. Firmware und Pin-Belegung kommen ohne Installation über Microsoft Edge oder Google Chrome auf das Board.

1

Firmware flashen

Board wählen, Port oder DFU-Gerät wählen, fertig. Leonardo, Pro Micro, Uno, Mega 2560, 32U2-Breakout und Arduino Due – ohne avrdude, FLIP oder bossac.

Konfigurieren

Pins für Ausgänge, Taster und Achsen zuweisen, Joysticks kalibrieren, LED-Strip einrichten, Live-Anzeige – gespeichert im EEPROM des Boards.

Voraussetzungen

  • Microsoft Edge oder Google Chrome ab Version 89 auf Windows, macOS oder Linux (Firefox/Safari können keine USB-Geräte ansprechen).
  • Ein unterstütztes Board am USB. Für DFU unter Windows einmalig der WinUSB-Treiber (Zadig), unter Linux udev-Regeln – Details stehen im Flasher und in der README.
  • Die Seiten laufen vollständig im Browser; es werden keine Daten an einen Server gesendet.

Unterstützte Boards

  • Arduino Leonardo (ATmega32U4)
  • Arduino Pro Micro / Micro (ATmega32U4)
  • Arduino Uno R3 (ATmega328P + ATmega16U2)
  • Arduino Uno R1/R2 (ATmega328P + ATmega8U2)
  • Arduino Mega 2560 (ATmega2560 + ATmega16U2)
  • Breakout-Board ATmega32U2
  • Arduino Due (SAM3X8E, nativer USB-Port, 3,3 V) – BETA: eigene ARM-Firmware, gleiches Protokoll, noch ungetestet
Stand: Beta – die Firmware 2.1 ist übersetzt und geprüft, aber noch nicht an echter Hardware getestet. Rückmeldungen bitte als GitHub-Issue.
